# FlowGuard AI — Trained Models Directory

Model binary artifacts (`.pkl`, `.joblib`, `.pt`) are generated by running the training scripts:

```powershell
# Train incident detection model
python scripts/train_incident_model.py

# Train forecasting models (XGBoost, GRU, ST-GNN, Historical Baseline)
python scripts/train_forecasting_models.py
```

Generated model artifacts include:
- `incident_model.joblib` — Calibrated incident classifier (LightGBM/XGBoost)
- `forecast_xgboost_h15.pkl`, `h30.pkl`, `h45.pkl`, `h60.pkl` — Multi-horizon traffic congestion forecasters
- `forecast_gru_*.pkl` — GRU temporal models
- `forecast_st_gnn_*.pkl` — Spatial-temporal graph neural network models
- `forecast_historical_baseline_*.pkl` — Historical baseline reference models
